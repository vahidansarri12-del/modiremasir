# مدیر مسیر — مشاور هوشمند کسب‌وکار

## قانون طلایی
> اگر می‌خواهی نفر اول بازار خودت باشی — اولین یا بهترین — مدیر مسیرت باهاته.

## این چیه؟
یک مشاور هوشمند که به کسب‌وکارها کمک می‌کند:
- مشکل را تشخیص بدهند
- ریشه را پیدا کنند
- راه‌حل ساده بگیرند
- از بحران پیشگیری کنند

## چطور کار می‌کند؟
1. می‌پرسد: می‌خواهی اولین باشی یا بهترین؟
2. می‌پرسد: الان کجای بازار هستی؟
3. می‌پرسد: از کِی فروشت کم شده؟
4. می‌پرسد: مشتری قدیمی می‌رود یا جدید نمی‌آید؟
5. تا ریشه می‌رود.
6. راه‌حل ساده می‌دهد.

## چرا این؟
چون اکثر مشاورها در سوال اول می‌مانند.
من تا ریشه می‌روم. مدیر مسیرت می‌شم.
